Supplementary document

Install requirements.txt and requirements-docs.txt, then run from the repository root:

    python -m src.hydrogel_immune_ml.supplementary
    python -m src.hydrogel_immune_ml.supplementary --verify

The builder reads current validation, case, t-SNE and Pareto outputs; it does not fit
models. It checks the archived source, dataset revision and model configuration,
then records all numerical and figure input hashes in supplementary_release_20261020.json.
The source document remains in docs/source. Build the model and interpretation outputs
before regenerating the document, and refresh the release checksums when making a new release.

The publication filenames retain 20261019 because that date identifies the fixed
letter mapping. data/publication/release_manifest.json identifies the 20261020 dataset
revision. Letters are nominal categories decoded before preprocessing; they are not
ordinal predictors. No letters are reassigned when counts change.

Windows visual QA uses Word without a visible window, opens the document read-only,
exports PDF, and renders pages with a supplied Poppler executable:

    ./docs/render_supplementary.ps1 -PdfToPpm <absolute-path-to-pdftoppm.exe>

Review every generated page before release. QA PDFs and page PNGs are intermediate
files under tmp; the delivered document is the DOCX in docs.
