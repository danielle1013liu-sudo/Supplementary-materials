For the second study, the control C (TNF-0015 / IL10-0015) is low in both datasets. The three CG/3MNP/5MNP differences are a genuine unresolved cross-target coding discrepancy. No source evidence justifies a target-dependent crosslink level for the same material. The current categories, predictions and fitted pipelines have not been changed. Choosing a harmonised category requires a separate authorised scientific revision, including assessment of its downstream effects.
